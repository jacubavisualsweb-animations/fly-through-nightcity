# Night City — After Hours

A small, dependency-free night-flight experience made with HTML, CSS, and Canvas.

## Run

Open `index.html` in a modern browser, or serve this directory with any static file server.

## Controls

- Press **Begin Flight** or **Space** to start; press it again to pause or resume.
- Use **← / →** or **A / D** to steer. Move or drag the pointer to steer.
- Use the **×1** button to cycle through flight speeds.
